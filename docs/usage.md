# 功能与交互

## 功能范围

| 模块     | 内容                                                                           |
| -------- | ------------------------------------------------------------------------------ |
| 基础日历 | 公历、农历、星期、节气、传统节日、公历节日                                     |
| 黄历     | 宜忌、建除十二神、神煞、二十八宿、胎神、五行、彭祖百忌、物候、数九三伏         |
| 附加信息 | 干支、生肖、星座、月相、纳音、小六壬、六曜、九星                               |
| 视图     | 月视图、日详情侧栏、年视图（12 个月缩略 + 节气表 + 假期表）、时间轴            |
| 工具     | 日期换算（公历↔农历↔回历↔藏历↔儒略日）、择日区间检索、八字排盘                 |
| 外观     | 两套可切换主题（现代简约 / 中国传统）× 浅色深色 × 跟随系统                     |
| 设置     | 独立设置界面：外观 / 显示 / 数据 / 作者信息 / 第三方许可 / 资产署名 / 运行环境 |
| 交互     | 全键盘导航、可切换的快捷键说明、ARIA 网格语义、选中日期朗读                    |

## 视图

| 视图   | 说明                                                                        |
| ------ | --------------------------------------------------------------------------- |
| 月视图 | 整月网格，单元格显示公历/农历/节日/节气，右侧为选中日期的详情侧栏           |
| 年视图 | 12 个月缩略网格 + 全年节气表 + 假期表，用于横向对比                         |
| 时间轴 | 以选中日期为锚点连续滚动，虚拟滚动只渲染可见行（`@tanstack/react-virtual`） |
| 工具   | 三个子工具：日期换算、择日检索、八字排盘                                    |

详情侧栏（黄历面板）按 `DayInfo` 渲染：农历日期、干支、生肖、星座、月相、纳音、宜忌、建除十二神、
神煞、二十八宿、胎神、五行、彭祖百忌、物候、数九三伏。可在设置里整体关闭（`显示黄历`）。

看不懂的标签可以**悬停或 `Tab` 聚焦**看释义，**点击**展开带出处的详情，`Esc` 或点击别处
关闭。宜忌条目（宜做什么、忌做什么）也在此列。**没找到释义的标签同样能悬停**——浮层会说
「暂无释义」、为什么缺，以及能去哪里查。覆盖范围与数据来源见 [glossary.md](glossary.md)。

三个工具页都接受当前选中日期作为默认输入，检索结果可以点回月视图定位。

## 设置项

设置界面按区块划分：

| 区块       | 内容                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 外观       | 主题族（现代简约 / 中国传统）、外观（跟随系统 / 浅色 / 深色）        |
| 显示       | 周一为一周首日、显示黄历、术语说明、启动时打开的视图                 |
| 数据       | 数据目录、设置文件路径（只读展示，说明所有设置只保存在本机、不上传） |
| 作者信息   | 应用名与版本、作者（运行时读取随包发布的 `package.json`）            |
| 第三方许可 | 与 [licensing.md](licensing.md) 同一份清单                           |
| 资产署名   | 应用图标来源                                                         |
| 运行环境   | Electron / Chromium / Node.js 版本                                   |

设置写入 `%APPDATA%\万年历\settings.json`（路径由 `productName` 决定，见
[packaging.md](packaging.md)）。

## 键盘快捷键

应用内点「快捷键」按钮或按 `?` 可查看同一份说明。

| 按键              | 作用                        |
| ----------------- | --------------------------- |
| `←` / `→`         | 前一天 / 后一天             |
| `↑` / `↓`         | 前一周 / 后一周             |
| `PgUp` / `PgDn`   | 前一个月 / 后一个月         |
| `Shift + PgUp/Dn` | 前一年 / 后一年             |
| `T` 或 `Home`     | 回到今天                    |
| `Alt + 1…4`       | 切换月 / 年 / 时间轴 / 工具 |
| `?`               | 显示或隐藏快捷键说明        |
| `Esc`             | 关闭说明                    |

焦点在输入框内时，除 `Esc` 外的按键都交给输入框处理。日期网格使用 ARIA `grid` 语义，
方向键在其中移动的是 `aria-activedescendant` 指向的单元格。
